# Memory Bank

Your memory resets completely between sessions.
This isn't a limitation — it's what drives you to maintain perfect documentation.
After each reset, rely entirely on the Memory Bank to understand the project and continue your work effectively.
At the start of every task, read all Memory Bank files in the `memory-bank/` directory.
This step is mandatory.
